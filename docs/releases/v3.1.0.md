# MasCloner v3.1.0 Release Notes

**Release Date**: September 2026  
**Target Git Branch**: `ver-3-1`  
**Authoritative Version**: `3.1.0`

---

## 🌟 Executive Summary

MasCloner **v3.1.0** delivers a complete architectural revamp of the web user interface, transforming it from a fragmented multi-file prototype into an operator-grade single-mission console.

The application’s sole focus—**continuously and reliably syncing two fixed folders from Google Drive to Nextcloud forever**—is now the centerpiece of the user experience. All folder picker bloat and multi-page configuration redundancy have been removed in favor of high-signal status indicators, live telemetry streaming, and on-demand endpoint verification.

---

## 🚀 Key Highlights & New Capabilities

### 1. Declarative Navigation & Unified Security Boundary
- **Streamlit 1.38 `st.navigation` Router**:
  Replaced brittle filesystem-based numbered files (`2_Settings.py`, `3_Runs_and_Events.py`, etc.) with a declarative three-section navigation structure:
  - **Operations**: `Live Dashboard`, `Live Monitor`, `Run History & Audit`
  - **Configuration**: `Storage & Connections`, `Schedule & Engine`
  - **System**: `Retention & Backups`, `Diagnostics`
- **Centralized Authentication Boundary**:
  All subpages are unconditionally protected by `require_auth(api)` at the router entry point (`Home.py`), eliminating previous vulnerabilities where sidebar navigation bypassed login guards.

### 2. Operations — High-Signal Live Dashboard & Active `SyncRoute` Card
- **Permanent SyncRoute Display**: Shows the configured Google Drive source (`gdrive:`) and Nextcloud destination (`ncwebdav:`) with live endpoint connectivity badges.
- **⚡ Verify Endpoints**: 1-click live backend probe to both Google Drive and Nextcloud WebDAV to ensure credentials and endpoints are functional.
- **Immediate Operational Controls**: "Sync Now" (with auto-redirect to Live Monitor), "Stop Sync", and "Pause / Resume Schedule" toggles.
- **Top Hero Status Bar**: Real-time status pill (`🟢 Engine Idle` vs `🔵 Sync #ID`), schedule cadence, next run time, and total run counter.

### 3. Operations — Dedicated Live Monitor with Non-Blocking Streaming
- **Isolated Telemetry Fragment**: Powered by `@st.fragment(run_every="2s")`, streaming live progress, current active file, transfer speed, and elapsed time without halting python execution threads or re-rendering the full page DOM.
- **Console Log Stream**: Live log viewer with log level filtering (`All Logs`, `Errors & Warnings Only`, `Errors Only`) and stream pause/resume controls.
- **Persistent Completion Banner**: Once a run completes, displays final stats and clear action buttons to return to Dashboard or drill down into History.

### 4. Operations — Filterable Run History with FileEvent Audit Drawer
- **Filterable Matrix**: Filter historical runs by canonical `SyncStatus` (`completed`, `failed`, `aborted`, `skipped`, `running`) and limit.
- **FileEvent Audit Drawer**: Expandable event list detailing file mutations (`[ADDED]`, `[UPDATED]`, `[ERROR]`, `[CONFLICT]`) with file sizes and exact rclone error messages.
- **Audit Export**: 1-click `Download Run Audit (CSV)` button for offline compliance and troubleshooting.

### 5. Configuration — Storage & Connections with Advanced Path Editor
- **Side-by-Side Endpoint Cards**: Visual health status, token re-authentication forms, and custom OAuth client credentials inputs.
- **Advanced Mode (Collapsed Accordion)**: Direct path inputs with immediate SQLite persistence, plus optional folder browsing when intentional sync path relocations are needed.

### 6. Configuration — Schedule & Engine Performance Tuning
- **Cadence Sliders with Launch Window Preview**: Adjust sync intervals (1m–24h) and jitter (0–300s) with live human-readable launch window calculations.
- **1-Click Engine Presets**: Instantly apply tested rclone profiles:
  - *Conservative* (low resource, 4 transfers / 8 checkers)
  - *Balanced* (recommended, 8 transfers / 16 checkers)
  - *High-Throughput* (fast network, 16 transfers / 32 checkers)
- **Advanced Rclone Parameters**: Fine-tune `--drive-chunk-size`, `--buffer-size`, `--tpslimit`, and `--fast-list`.

### 7. System — Retention Policy, Verified Backups & Diagnostics
- **60-Day Retention Management**: Interactive retention status with Dry Run preview simulation and manual cleanup triggers.
- **Verified SQLite Backups**: Trigger online `VACUUM INTO` snapshots with SHA-256 integrity hash verification and size reporting.
- **Preflight Diagnostics Suite**: 1-click non-destructive probe across API health, authentication, SQLite engine, cloud remotes, and configuration consistency, with exportable JSON reports.
