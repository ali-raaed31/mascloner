# MasCloner v3.1.5 Release Notes

**Release Date**: September 2026  
**Target Git Branch**: `ver-3.1.5`  
**Authoritative Version**: `3.1.5`

---

## 🌟 Executive Summary

MasCloner **v3.1.5** delivers an ergonomic and operational modernization of the frontend and API runtime, upgrading the web engine to **Streamlit 1.63.0** and the REST API to **FastAPI 0.141.1** (Starlette 1.6.0). 

Building upon the single-mission console architecture established in v3.1.0, v3.1.5 leverages modern Streamlit 1.63 capabilities—including interactive pill selectors, tactile container cards, live elapsed-time progress indicators, scrollable code terminal outputs, and non-reloading data export buttons—providing an agile, zero-friction operator experience.

---

## 🚀 Key Highlights & New Capabilities

### 1. Modern Interactive Selectors (`st.pills` & `st.segmented_control`)
- **Run History Status Filtering (`st.pills`)**:
  Replaced dropdown menus with 1-click status pill chips (`[All] [Completed] [Failed] [Aborted] [Skipped] [Running]`), allowing operators to rapidly filter through runs.
- **Console Log Severity Filter (`st.segmented_control`)**:
  Replaced dropdown selector in the Live Monitor with segmented control options (`All Logs`, `Errors & Warnings Only`, `Errors Only`).
- **Engine Performance Profiles (`st.segmented_control`)**:
  Upgraded the 1-click engine tuning options in the Schedule & Engine view into a segmented selector, providing instant switching between *Conservative*, *Balanced*, and *High-Throughput* rclone configurations.
- **Google Drive OAuth Scope Selector (`st.pills`)**:
  Streamlined OAuth scope selection in Storage & Connections.

### 2. Tactile Card Containers & Bordered Metrics (`border=True`)
- **Active SyncRoute Endpoint Cards**:
  Wrapped Google Drive (`gdrive:`) and Nextcloud WebDAV (`ncwebdav:`) cards in native `st.container(border=True)` for distinct visual containment and physical boundaries.
- **Tactile Metric Cards**:
  Updated execution duration, volume synced, files mutated, and database retention stats to use native `st.metric(..., border=True)`.
- **Storage Connection Tiles**:
  Wrapped connection status panels for both Google Drive and Nextcloud in bordered containers.

### 3. Real-Time Operational Feedback (`show_time=True`)
- **Live Elapsed Probing Spinners**:
  Added live second counters to `st.spinner(..., show_time=True)` across all long-running operational actions:
  - Endpoint verification probes (`⚡ Verify Endpoints`) in Dashboard and Storage views.
  - Subsystem preflight diagnostic runs in Diagnostics view.
  - Consistent database recovery snapshot generation and SHA-256 calculation.
  - Manual 60-day retention cleanup passes.

### 4. Scrollable Terminal Stream & Non-Reloading Exports
- **Scrollable Real-Time Console Stream (`st.code(..., height=420)`)**:
  Console logs stream into a dedicated, scrollable monospace terminal window with a fixed height, eliminating erratic page scrolling during active sync runs.
- **Non-Reloading Downloads (`on_click="ignore"`)**:
  Configured `st.download_button(..., on_click="ignore")` for Run Audit CSVs and Diagnostics JSON reports, ensuring file exports do not trigger full Streamlit app reruns or reset interactive filter states.

### 5. Runtime & Package Modernization
- **Streamlit 1.63.0**: Upgraded from 1.38.0 with enhanced fragment reactivity, reduced websocket latency, and hardened origin verification.
- **FastAPI 0.141.1**: Upgraded from 0.115.0 to align with Starlette 1.6.0 and modern ASGI specifications while maintaining 100% backwards compatibility with all REST endpoints.
- **Qualification**: Verified with 100% test pass rate across all 189 tests.
